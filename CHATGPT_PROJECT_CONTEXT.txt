================================================================================
  1. PROJECT OVERVIEW
================================================================================

NAME:    VoltGuard
TYPE:    Physics-Aware Intrusion Detection System for ICS/SCADA environments
PURPOSE: Validates industrial control commands (Modbus-style) against a physics
         simulation of a pipeline. Commands that would cause the physical system
         to enter a dangerous state (overpressure or overflow) are BLOCKED
         (DROP). Safe commands are ALLOWED. All decisions are logged and shown
         in a professional web dashboard.

KEY CONCEPT: "Physics-aware" means the IDS does not just look at network
signatures — it simulates what the physical system would actually DO if the
command were executed. This makes it impossible for an attacker to craft a
packet that "looks safe" but would cause real-world damage.

LANGUAGES USED:
  - Python 3.13   (generator, interceptor, physics engine, web backend)
  - Rust          (decision engine — optional, Python fallback provided)
  - JavaScript    (web dashboard frontend)
  - C++ / Qt6     (desktop dashboard — optional)
  - Modelica      (high-fidelity physics model — optional, Python fallback used)


================================================================================
  2. ARCHITECTURE & DATA FLOW
================================================================================

  [generator.py]
      Produces 20 synthetic Modbus FC16 (write register) commands
      Output: packet_interceptor/sample_log.jsonl
      Each record: { device_id, function_code, register, value, source }

  [interceptor.py]  ← MAIN ORCHESTRATOR
      Reads sample_log.jsonl line by line
      For each command:
        1. Calls simulate_pipeline.py <value>  (subprocess)
           Returns: { pressure_bar, flow_rate, state }
        2. Calls decision engine (Rust binary or Python fallback)
           Returns: { action: "ALLOW"|"DROP", reason }
        3. Merges all fields → writes to output/decisions.jsonl
      Output: output/decisions.jsonl

  [simulate_pipeline.py]
      Accepts a float cmd value as CLI argument
      Tries OpenModelica (OMPython) first; falls back to Python math:
        pressure = 6.0 + 0.12*cmd + 0.8*(1.0 + 0.015*cmd)
        flow     = 1.0 + 0.015*cmd
        state    = "Catastrophic Failure" if pressure>12.0 or flow>5.0
      Returns JSON to stdout

  [decision_engine (Rust)]
      Reads JSON from stdin: { pressure_bar, flow_rate, state }
      Logic: DROP if state=="Catastrophic Failure" OR pressure>12.0 OR flow>5.0
      Returns JSON to stdout: { action, reason }

  [web/backend/app.py]  ← FastAPI server on port 8000
      GET  /              → serves index.html
      GET  /api/decisions → returns all records from decisions.jsonl
      GET  /api/stats     → total/allow/drop counts and percentages
      POST /api/run       → runs generator + interceptor synchronously
      GET  /api/stream    → SSE live stream of pipeline output
      GET  /docs          → Swagger UI (auto-generated by FastAPI)

  [web/frontend/]  ← Single-page dashboard (vanilla HTML/CSS/JS)
      4 sections: Dashboard, Decision Log, Live Pipeline, API Explorer
      Charts: Donut (distribution), Bar+Line (pressure/flow), Timeline
      Features: table filter, CSV export, live terminal, API tester

  [dashboard/ (Qt6 C++)]  ← Optional desktop viewer
      Reads output/decisions.jsonl at startup
      Shows table: Device | Action | State | Pressure | Flow | Value
      Requires: Qt6, CMake, C++17 compiler

================================================================================
  3. PHYSICS THRESHOLDS
================================================================================

  Parameter       Safe Limit    Action if Exceeded
  --------------- ------------- ----------------------
  pressure_bar    <= 12.0 bar   DROP — Catastrophic Failure
  flow_rate       <= 5.0        DROP — Catastrophic Failure
  Both within     —             ALLOW — Safe

  Physics formula (Python):
    pressure = 6.0 + 0.12 * cmd + 0.8 * (1.0 + 0.015 * cmd)
    flow     = 1.0 + 0.015 * cmd
    where cmd = Modbus register value (valve position, integer from set:
                5, 12, 25, 40, 55, 80)

  Sample output values:
    cmd=5  → pressure=7.460,  flow=1.075  → ALLOW (Safe)
    cmd=12 → pressure=8.384,  flow=1.180  → ALLOW (Safe)
    cmd=25 → pressure=10.100, flow=1.375  → ALLOW (Safe)
    cmd=40 → pressure=12.080, flow=1.600  → DROP  (Catastrophic Failure)
    cmd=55 → pressure=14.060, flow=1.825  → DROP  (Catastrophic Failure)
    cmd=80 → pressure=17.360, flow=2.200  → DROP  (Catastrophic Failure)

import json
import subprocess
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
SIM = ROOT / "physics_engine" / "simulate_pipeline.py"
_RUST_BASE = ROOT / "decision_engine" / "target"
RUST_BIN = (
    _RUST_BASE / "release" / "decision_engine.exe"
    if (_RUST_BASE / "release" / "decision_engine.exe").exists()
    else _RUST_BASE / "release" / "decision_engine"
    if (_RUST_BASE / "release" / "decision_engine").exists()
    else None
)
LOG = Path(__file__).with_name("sample_log.jsonl")
OUT = ROOT / "output" / "decisions.jsonl"

def simulate(value: float) -> dict:
    out = subprocess.check_output([sys.executable, str(SIM), str(value)], text=True)
    return json.loads(out.strip())

def decide(sim: dict) -> dict:
    if RUST_BIN is not None and Path(RUST_BIN).exists():
        p = subprocess.run([str(RUST_BIN)], input=json.dumps(sim), text=True,
                           capture_output=True, check=True)
        return json.loads(p.stdout.strip())
    blocked = (sim["state"] == "Catastrophic Failure"
               or sim["pressure_bar"] > 12.0
               or sim["flow_rate"] > 5.0)
    if blocked:
        return {"action": "DROP", "reason": "Physics threshold exceeded"}
    return {"action": "ALLOW", "reason": "Within safe bounds"}

def main():
    OUT.parent.mkdir(parents=True, exist_ok=True)
    if not LOG.exists() or LOG.stat().st_size == 0:
        subprocess.check_call([sys.executable, str(Path(__file__).with_name("generator.py"))])
    with LOG.open("r", encoding="utf-8") as f, OUT.open("w", encoding="utf-8") as o:
        for line in f:
            line = line.strip()
            if not line: continue
            cmd = json.loads(line)
            sim = simulate(cmd["value"])
            decision = decide(sim)
            record = {**cmd, **sim, **decision}
            o.write(json.dumps(record) + "\n")
            status = "DROP" if decision["action"] == "DROP" else "ALLOW"
            print(f"{status} | value={cmd['value']:5.1f} | pressure={sim['pressure_bar']:.3f} "
                  f"bar | flow={sim['flow_rate']:.3f} | state={sim['state']}")

if __name__ == "__main__":
    main()

import json, sys
from pathlib import Path
try:
    from OMPython import OMCSessionZMQ
except Exception:
    OMCSessionZMQ = None

def fallback_sim(cmd: float):
    pressure = 6.0 + 0.12 * cmd + 0.8 * (1.0 + 0.015 * cmd)
    flow = 1.0 + 0.015 * cmd
    state = "Catastrophic Failure" if pressure > 12.0 or flow > 5.0 else "Safe"
    return {"pressure_bar": round(pressure, 3), "flow_rate": round(flow, 3), "state": state}

def run(cmd: float):
    if OMCSessionZMQ is None:
        return fallback_sim(cmd)
    try:
        omc = OMCSessionZMQ()
        mo_file = str(Path(__file__).with_name("pipeline.mo"))
        omc.sendExpression(f'loadFile("{mo_file.replace(chr(92), "/")}")')
        omc.sendExpression("instantiateModel(Pipeline)")
        res = omc.sendExpression(f"simulate(Pipeline, stopTime=1.0, numberOfIntervals=10, cmd={cmd})")
        if isinstance(res, dict) and "pressure_bar" in res and "flow_rate" in res:
            pressure = float(res["pressure_bar"])
            flow = float(res["flow_rate"])
            state = "Catastrophic Failure" if pressure > 12.0 or flow > 5.0 else "Safe"
            return {"pressure_bar": round(pressure, 3), "flow_rate": round(flow, 3), "state": state}
    except Exception:
        pass
    return fallback_sim(cmd)

if __name__ == "__main__":
    cmd = float(sys.argv[1]) if len(sys.argv) > 1 else 0.0
    print(json.dumps(run(cmd)))

use serde::{Deserialize, Serialize};
use std::io::{self, Read};

#[derive(Deserialize)]
struct SimInput {
    pressure_bar: f64,
    flow_rate: f64,
    state: String,
}

#[derive(Serialize)]
struct Decision {
    action: String,
    reason: String,
}

fn main() {
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap_or(0);
    let sim: SimInput = serde_json::from_str(&input).unwrap_or(SimInput {
        pressure_bar: 0.0,
        flow_rate: 0.0,
        state: "Safe".to_string(),
    });
    let blocked = sim.state == "Catastrophic Failure"
               || sim.pressure_bar > 12.0
               || sim.flow_rate > 5.0;
    let decision = Decision {
        action: if blocked { "DROP".into() } else { "ALLOW".into() },
        reason: if blocked { "Physics threshold exceeded".into() }
                else       { "Within safe bounds".into() },
    };
    println!("{}", serde_json::to_string(&decision).unwrap());
}

"""VoltGuard Web Backend — FastAPI"""
import asyncio, json, subprocess, sys
from pathlib import Path
from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse, StreamingResponse, JSONResponse
from fastapi.staticfiles import StaticFiles
from fastapi.middleware.cors import CORSMiddleware

ROOT        = Path(__file__).resolve().parents[2]
INTERCEPTOR = ROOT / "packet_interceptor" / "interceptor.py"
GENERATOR   = ROOT / "packet_interceptor" / "generator.py"
DECISIONS   = ROOT / "output" / "decisions.jsonl"
FRONTEND    = Path(__file__).resolve().parent.parent / "frontend"

app = FastAPI(title="VoltGuard API", version="1.0.0")
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])
app.mount("/static", StaticFiles(directory=str(FRONTEND / "static")), name="static")

def _read_decisions():
    if not DECISIONS.exists() or DECISIONS.stat().st_size == 0:
        return []
    records = []
    with DECISIONS.open(encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                try: records.append(json.loads(line))
                except json.JSONDecodeError: pass
    return records

@app.get("/", response_class=HTMLResponse)
async def index():
    return HTMLResponse(content=(FRONTEND / "index.html").read_text(encoding="utf-8"))

@app.get("/api/decisions")
async def get_decisions():
    records = _read_decisions()
    if not records:
        return JSONResponse({"records": [], "message": "No decisions yet."})
    return {"records": records}

@app.get("/api/stats")
async def get_stats():
    records = _read_decisions()
    total = len(records)
    allow = sum(1 for r in records if r.get("action") == "ALLOW")
    drop  = total - allow
    return {"total": total, "allow": allow, "drop": drop,
            "allow_pct": round(allow/total*100,1) if total else 0,
            "drop_pct":  round(drop/total*100,1)  if total else 0}

@app.post("/api/run")
async def run_pipeline():
    try:
        loop = asyncio.get_event_loop()
        await loop.run_in_executor(None, lambda: subprocess.check_call(
            [sys.executable, str(GENERATOR)], timeout=30))
        await loop.run_in_executor(None, lambda: subprocess.check_call(
            [sys.executable, str(INTERCEPTOR)], timeout=60))
        return {"status": "success", "message": "Pipeline completed successfully."}
    except subprocess.CalledProcessError as exc:
        return JSONResponse(status_code=500, content={"status":"error","message":str(exc)})
    except subprocess.TimeoutExpired:
        return JSONResponse(status_code=500, content={"status":"error","message":"Timed out."})

@app.get("/api/stream")
async def stream_pipeline(request: Request):
    async def generate():
        yield "retry: 0\n"
        yield _sse({"msg": "Starting pipeline...", "type": "info"})
        yield _sse({"msg": "[1/2] Generating Modbus commands...", "type": "info"})
        try:
            loop = asyncio.get_event_loop()
            await loop.run_in_executor(None,
                lambda: subprocess.run([sys.executable, str(GENERATOR)], timeout=30, check=True))
            yield _sse({"msg": "[1/2] sample_log.jsonl created.", "type": "info"})
        except Exception as exc:
            yield _sse({"msg": f"Generator error: {exc}", "type": "error"})
            yield _sse({"msg": "Pipeline failed.", "type": "done"})
            return
        yield _sse({"msg": "[2/2] Running detection pipeline...", "type": "info"})
        try:
            proc = await asyncio.create_subprocess_exec(
                sys.executable, str(INTERCEPTOR),
                stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.STDOUT)
            async for raw in proc.stdout:
                line = raw.decode("utf-8", errors="replace").rstrip()
                if not line: continue
                if await request.is_disconnected():
                    proc.kill(); return
                t = "drop" if "DROP" in line else "allow" if "ALLOW" in line else "info"
                yield _sse({"msg": line, "type": t})
            await proc.wait()
        except Exception as exc:
            yield _sse({"msg": f"Interceptor error: {exc}", "type": "error"})
        yield _sse({"msg": "Pipeline complete!", "type": "done"})

    return StreamingResponse(generate(), media_type="text/event-stream",
        headers={"Cache-Control":"no-cache","X-Accel-Buffering":"no","Connection":"keep-alive"})

def _sse(payload: dict) -> str:
    return f"data: {json.dumps(payload)}\n\n"

#include "mainwindow.h"
#include <QCoreApplication>
#include <QVBoxLayout>
#include <QWidget>
#include <QHeaderView>
#include <QFile>
#include <QJsonDocument>
#include <QJsonObject>

MainWindow::MainWindow(QWidget *parent) : QMainWindow(parent) {
    auto *central = new QWidget(this);
    auto *layout = new QVBoxLayout(central);
    table = new QTableWidget(0, 6, this);
    table->setHorizontalHeaderLabels({"Device","Action","State","Pressure","Flow","Value"});
    table->horizontalHeader()->setSectionResizeMode(QHeaderView::Stretch);
    log = new QTextEdit(this);
    log->setReadOnly(true);
    layout->addWidget(table);
    layout->addWidget(log);
    setCentralWidget(central);
    setWindowTitle("VoltGuard Dashboard");
    loadLog();
}

void MainWindow::loadLog() {
    QString path = QCoreApplication::applicationDirPath() + "/../output/decisions.jsonl";
    QFile file(path);
    if (!file.open(QIODevice::ReadOnly | QIODevice::Text)) {
        log->setPlainText("No output/decisions.jsonl found yet. Run interceptor.py first.");
        return;
    }
    while (!file.atEnd()) {
        QByteArray line = file.readLine().trimmed();
        if (line.isEmpty()) continue;
        QJsonDocument doc = QJsonDocument::fromJson(line);
        if (!doc.isObject()) continue;
        QJsonObject obj = doc.object();
        int row = table->rowCount();
        table->insertRow(row);
        table->setItem(row,0,new QTableWidgetItem(QString::number(obj["device_id"].toInt())));
        table->setItem(row,1,new QTableWidgetItem(obj["action"].toString()));
        table->setItem(row,2,new QTableWidgetItem(obj["state"].toString()));
        table->setItem(row,3,new QTableWidgetItem(QString::number(obj["pressure_bar"].toDouble(),'f',2)));
        table->setItem(row,4,new QTableWidgetItem(QString::number(obj["flow_rate"].toDouble(),'f',2)));
        table->setItem(row,5,new QTableWidgetItem(QString::number(obj["value"].toDouble(),'f',2)));
        log->append(line);
    }
}

================================================================================
  20. KNOWN DESIGN DECISIONS & TRADEOFFS
================================================================================

  1. Python fallback for Rust:
     The interceptor checks for the Rust binary at startup. If not found, it
     uses an inline Python function with identical threshold logic. This means
     the project works out-of-the-box without Rust installed.

  2. SSE for live streaming:
     /api/stream uses Server-Sent Events (one-way server→browser). retry:0
     disables auto-reconnect to prevent the "too many requests" bug. The
     browser EventSource is explicitly closed when type=="done" is received.

  3. Async subprocess streaming:
     The FastAPI stream endpoint uses asyncio.create_subprocess_exec so the
     event loop is not blocked while waiting for interceptor output.

  4. Physics model fallback:
     simulate_pipeline.py tries OpenModelica first (high-fidelity Modelica
     simulation). If OMPython is not installed or fails, it uses the Python
     math formula. Results are identical for the tested command values.

  5. No database:
     All state is stored in JSONL flat files (decisions.jsonl, sample_log.jsonl).
     Simple, portable, no setup required.

  6. No authentication:
     The web server has no auth. It is designed for local/lab use only.
